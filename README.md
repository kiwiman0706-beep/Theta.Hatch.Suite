## メモ

- 最新版は各リポジトリの README または `versionName` から拾った値です。「—」は確認できなかったもの。
- Meishi.Hatch・Mensetsu.Hatch・Memo.Hatch・Oekaki.Hatch は「Theta Vault」（Obsidian で開ける Markdown フォルダ）を共有する設計です。シリーズ共通の約束は [MeishiApp/docs/THETA_HATCH_SPEC.md](https://github.com/kiwiman0706-beep/MeishiApp/blob/HEAD/docs/THETA_HATCH_SPEC.md)。
- 多くの作品は README に「実機での確認はまだ」と書かれています。
- Claude スレッドは各リポジトリで開発した主なスレッドです。
